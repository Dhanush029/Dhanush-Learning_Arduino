# LED Blinking

This is the most basic arduino program. By making this program, I learnt the use of the digitalWrite() command. It sends a digital signal which can only have two states (HIGH OR LOW) to a digital input pin. In this case, pin 13.

There is an LED on the arduino which is already connected to pin 13, so when this code is run the built-in LED blinks. Alternatively, an LED bulb can be connected through a circuit to this pin and it will blink as well. Moreover, this type of program is not limited to just pin 13. Any of the other digital pins can be used as long as the pin is specified in the pinMode() and digitalWrite() commands.
